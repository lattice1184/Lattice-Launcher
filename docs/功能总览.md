# Lattice 启动器功能总览

> 2026-08-17 整理。按**功能域**组织（非代码模块），每域下列出配套集成的具体功能。
> 依据：`src/Launcher.Core` + `PCL.Core` 源码盘点。

---

## 1. 下载引擎（最完整的功能簇）

### 1.1 多源竞速（Race）
- 同一目标 URL 解析出多个候选源，**并行竞速**，最先完成者胜出
- 每源独立 race 目标（`dest.race{URL哈希}`），中间文件天然隔离
- `RaceEliminateInterval`（默认 15s）定时淘汰落后源
- 节奏追踪（PaceTracker）：采样字节数/推送间隔，检测停滞、记录稳定领先，超阈值触发淘汰
- 竞速完成后合并写入最终目标文件

### 1.2 慢源检测与剔除
- SlowSourceDetector：按阈值速度 + 连续慢样本 + 探测时长判定慢源，主动 Abort
- SourceStats：每源成功/失败记录，下一轮按成绩**重排候选顺序**（Rank）
- 挂死源处理：8-14 watchdog 摘除的源本轮直接剔除（可能无视取消、锁着 .race/.tmp 文件）

### 1.3 断点续传
- `.tmp` 中间文件预写 → `Range` 请求续传
- 每源独立 `.parts` 分片，下轮可复用
- 中间文件清理策略（含历史遗留 .race*.parts 的回收）

### 1.4 重试与退避
- RetryPolicy：指数退避（Backoff）
- JsonException 等瞬时错误自动重试（500ms 延迟后重试）

### 1.5 任务管理（DownloadManager + DownloadTask）
- 单例 DownloadManager：**并发上限**控制、任务队列
- `Enqueue` / `EnqueueGroup`（组任务 = 多子任务加权汇总进度）
- 任务状态机：**挂起 Suspend / 恢复 Resume / 重试 Retry / 取消 Cancel / 阶段 SetStage**
- `SuspendAll` / `ResumeAll` 全局暂停恢复
- 自动重试（AutoRetryArgs，含尝试次数）
- 完成队列清理 `ClearFinished`
- 进度展示：字节文本（`123MB / 456MB`）、阶段名、百分比

### 1.6 进度上报
- ProgressReporter：字节/总量/阶段统一上报
- DownloadProgressHandler 回调链（单任务与组任务统一）

### 1.7 文件命名处理
- UriFileNameResolver：URL 提取文件名 → Content-Disposition 解析 → **非法字符净化**
- UniquePath：重名自动加序号

### 1.8 版本与加载器下载
- VersionInstaller：版本 JSON 获取（本地/远端）、版本安装、孤儿父版本清理、SafeId 防路径穿越
- VersionDownloadPipeline：按版本 JSON 下载 assets/libraries/客户端 jar 全链路
- LoaderService：Fabric/Forge/NeoForge/Quilt 加载器**版本列表 → 安装计划 → 安装**三步流程

### 1.9 整合包支持
- ModpackImporter：**CurseForge 整合包 + Modrinth mrpack 导入**（manifest 解析、CF 加载器 ID 解析、Zip 解压）
- MrpackExporter：当前版本导出为 mrpack（含依赖选择）
- ModpackInstaller：导入后按依赖清单逐项安装

### 1.10 源解析与加速
- ThirdPartyDlSourceResolver：官方 URL → **第三方镜像源解析**（BMCLAPI 等）
- IDlSourceMapper：主/备映射链，可叠加
- GitHub 直连：GitHubApiDirect 获取签名 URL（绕过 302 限流）
- 动态分块：ShouldUpgradeChunks 按实测速度提升分块数；**渐进式限流 CDN 识别**（IsProgressiveThrottleCdn）自动降档

### 1.11 网络检测
- NetworkChecker：多主机连通性探测、HTTP 探测（延迟测速）
- HttpClientPool：共享 SocketsHttpHandler 连接池

### 1.12 安装标记
- InstallMarker：安装完成标记 / 预取标记 / 页面展示控制（避免重复安装提示）

### 1.13 配置化
- DownloadOptions：竞速淘汰间隔等全部可配，`FromSettings` 从设置读取

## 2. 版本与游戏目录

- **版本清单**：VersionManifestService 获取/刷新/缓存官方版本清单，支持强制刷新
- **版本分类**：VersionClassifier 区分 release / snapshot / old 及愚人节版本
- **版本过滤**：默认只展示 ≥1.16 的可用版本
- **已装实例扫描**：ScanUsableInstances 多目录扫描，父版本 → 子实例关系图（BuildChildrenMap），外来源标记清理
- **版本 JSON 合并**：VersionJsonMerger 合并父版本继承链
- **游戏目录多源**：GameDirectory 自建目录优先（D 盘 → Downloads 回退）、PCL/官方目录识别扫描、**来源标签**（来源不同显示不同标签）

---

## 3. 游戏启动

- **Java 发现**：JavaManager 六路扫描——注册表 / PATH / 常见路径 / Microsoft Store / PE 头解析 / 手动添加；可用性检查（IsStillAvailable）
- **Java 自动选配**：JavaSelector 按版本要求（required major，支持父版本继承）最佳匹配；SelectSuitableJavaAsync 版本区间筛选
- **启动参数构建**：JavaArgumentsBuilder 规则解析（RulesResolver：OS/架构/特性）、library 参数、classpath 拼接
- **内存管理**：MemoryAllocator 自动计算（按系统内存）、手动配置；PerformanceProfile 输出 Xmx/Xms/GC 参数（G1GC 等）
- **原生库**：ExtractNatives 解压 natives 并校验
- **启动流程**：GameLaunchService 完整启动链（启动 → 退出码读取 → 崩溃检查）
- **进程优先级**：GamePriority 映射（高/普通/低）
- **皮肤包**：SkinPack 强制写入自定义皮肤（PNG 头解析校验尺寸、按版本选 pack format）
- **自动中文**：AutoChinese 自动注入中文输入支持
- **安装器执行**：InstallerProcess 运行 Forge 等图形安装器

---

## 4. 模组生态（CurseForge / Modrinth / mcmod）

- **CurseForge**：搜索（分类/排序/游戏版本）、项目详情、文件列表（版本过滤 + **加载器过滤**）、最佳文件选择、单文件安装、**依赖自动安装**（含失败报告）、API key 校验、bundled key 混淆存储（非明文）
- **Modrinth**：搜索（facet 构建：类型/版本/加载器/分类）、中文查询转译、项目详情、版本列表、最佳版本选择（release 优先排序）、依赖安装
- **mcmod 桥接**：McmodSearchService 中文搜索 → 解析 Modrinth slug → 中文标题回显
- **依赖解析引擎**：ModDependencyResolver——visited 去重、已装兼容判断、未决依赖报告、跨源解析
- **跨源回退**：EcosystemDependencyAdapter 统一 resolver——CF 无依赖数据时自动回退 Modrinth 查同名项目（标题强匹配 + 确认）
- **收藏**：FavoritesService 项目收藏持久化
- **站点目录**：SiteCatalog 常用 MC 站点导航（官网/百科/皮肤站等分类）

---

## 5. 账号系统

- **微软登录**：MicrosoftAuth 完整 OAuth2 + PKCE + 设备码 + 静默刷新（RefreshMicrosoftAsync），clientId 远程下发（ClientIdRemote，PCL 同款"藏"）
- **LittleSkin**：OAuth 登录 + API——衣橱浏览（分页）、玩家列表、**一键应用皮肤**
- **离线账号**：OfflineUuid 稳定 UUID 生成（离线 + LittleSkin 两种模式）
- **账户管理**：AccountService 多账户持久化 / 切换 / 删除 / 登出

---

## 6. 诊断与自修复

- **日志诊断**：LogDiagnostics 退出码诊断 + 详细诊断（已知错误模式 → 修复建议），覆盖率含 main class 缺失等
- **文件完整性校验**：AutoRepairService.VerifyVersionAsync / VerifyFilesAsync——对照版本清单**逐文件 SHA 比对**（可选开关），损坏文件自动重下
- **下载哈希校验**：联机模块（EasyTier/Terracotta）SHA256 强制比对已知哈希，不符拒绝安装；mrpack 清单 sha1 校验
- **自动修复**：FixRedownload（重下损坏文件，带深度防递归）、FixNatives（重解压原生库）、FixServerJar
- **模组修复**：ModRepairService 扫描最新日志/崩溃报告 → 判定问题模组 → 修复报告
- **失败转译**：FailureDiagnostics 下载/启动/联机异常 → 人类可读诊断（ForDownload/ForLaunch/ForMultiplayer）

---

## 7. 联机系统

- **EasyTier 虚拟局域网**：模块自动获取（GitHub + 镜像多源）、**SHA256 强制校验**（锁版本 v2.6.4，哈希不符拒绝安装）、Host/Join 房码、虚拟 IP 分配（SHA256 哈希 → 10.144.144.x）、玩家状态刷新
- **Terracotta 联机（第二套）**：Gitee/GitHub 双源模块、**SHA256 必校验**（锁版本 0.4.2）、tar.gz 自解包、会话管理、**卡死实例清理**（KillStaleInstances 锁文件机制）
- **服务器状态 Ping**：McPingService modern（1.7+）+ LegacyMcPingService（老版本协议），返回 MOTD/在线人数/版本/Mod 列表；自动协议选择工厂
- **服务器地址解析**：ServerAddressResolver + 自研 DNS 查询（DnsQuery）——**SRV 记录解析**（_minecraft._tcp）、直连 IP 解析
- **大厅服务**：Lobby 控制器/信息提供/文本处理（联机大厅会话）
- **房码生成**：LobbyCodeGenerator 短码生成
- **框架协议**：Scaffolding 客户端/服务端 + 广播发现（BroadcastListener）

---

## 8. 服务器管理（一键开服）

- **服务器安装**：ServerInstaller 服务端 jar 下载（多源）、有效性校验（IsValidServerJar）、旧版目录迁移、默认 server.properties 生成、EULA 自动同意
- **服务器进程**：ServerProcess 启动（Java/内存/优先级）、**控制台命令发送**、优雅停止 / 强杀
- **服务器文件管理**：properties 键值读写、ops.json 管理、banned-players.json 管理（封禁/解封）、常用预设（SuggestionPresets）

---

## 9. UI 与体验

- **动画引擎**：PCL.Core 全套——20+ easing（Back/Bounce/Elastic/Exponential/Quintic…）、动画组（并行/顺序）、复合动画、WinMM 高精度时钟
- **主题系统**：ThemeService 深浅主题、色调配置（ToneProfile）、Lab 色彩空间、系统主题跟随
- **毛玻璃**：BlurBorder / AdaptiveBlur / EnhancedBlur / OptimizedBlur（多级性能档位）
- **SVG 图标**：SvgIcon 自绘解析器（path 解析、着色）
- **本地化**：LocalizationService 多语言、字体配置、格式转换
- **通知**：ToastNotification（WinRT 原生通知）
- **首页新闻**：NewsViewModel 官方新闻拉取展示
- **动效背景**：BackgroundPresenter 自适应背景色板（BackgroundPaletteMath 亮度检测 → 明暗色板）
- **灰度模式**：GrayProfile 低配/省电降级（禁用动效）
- **版本格式化**：McFormatter 版本显示规范化 + 中文维基链接生成

## 10. 基础设施

- **配置系统**：ConfigService JSON/YAML 双格式、**加密存储**（EncryptedFileConfigStorage）、迁移、变更事件、观察者
- **缓存**：SQLite 缓存（CacheService）+ 逐出策略（CacheEvictionService）+ 容量统计
- **网络层**：连接池复用、**系统代理管理**（HttpProxyManager 自动跟随/刷新）、HTTP 缓存 handler、**DNS 竞速**（WeightedDnsRacerClient 多 DNS 择优）、TCP 转发（TcpForward）
- **加密工具**：AES-CBC / AES-GCM / ChaCha20-Poly1305 多套加密实现
- **日志**：LogService 多级别、异常详情、调试开关
- **单实例**：SingleInstanceService 防重复启动
- **自动更新**：UpdateService / UpdateHelper + **BsDiff 二进制差分更新**
- **数据库**：SQLite DatabaseService（数据/缓存分层）
- **事件总线**：EventBusService 解耦通信
- **进程通信**：PipeComm 命名管道服务（进程白名单校验）；RpcService 本地 RPC
- **注册表监视**：RegistryChangeMonitor 监听注册表变更（Java 安装动态发现）
- **启动验证**：StartupService/StartupValidation 启动前系统检查；DependencyCheckService 系统依赖体检
- **生命周期**：IoC 依赖组 + 生命周期流程（LifecycleFlow）+ 状态机
- **任务中心**：TaskCenter 统一任务模型（进度/取消/暂停）
- **存储管理**：StorageScanner 分类扫描（日志/下载缓存等）→ 显示占用 → **一键清理**；容量上限（logs 200MB / downloads 2GB）
- **CLI 参数**：命令行解析（子命令/参数类型校验）
- **工具集**：哈希（MD5/SHA1/256/512/Murmur2）、相似度搜索（SimilaritySearch）、版本区间（VersionRange）、文件名校验器、编码检测、线程池（DualThreadPool / LimitedTaskPool）

---

## 11. 存档管理（被忽略的完整模块）

- **存档扫描**：SaveManager 扫描存档文件夹 → 加载存档信息（名称/版本/最后游玩/损坏检测）
- **全谱系解析**：NBT 解析器覆盖 **Pre-1.13 → 26.1+ 六个世代**（SaveParserFactory 按 dataVersion 自动选解析器），任意时代存档可读
- **存档编辑**：ISaveEditor 编辑链路（Pre261 / 261+ 两套编辑器）、改动事务（SaveChanges）、损坏存档异常分类（损坏/未找到）
- **存档导入**：SaveImportHelper 解包导入（自动定位存档根目录）
- **NBT 工具**：NbtFileHandler 通用 NBT 文件读写（含压缩格式）
- **数据版本边界**：DataVersionBoundaries 版本→dataVersion 映射（跨版本迁移判断）

---

## 12. 安全与隐私

- **密钥存储**：本地密钥加密（EncryptHelper）、CF key 混淆打包（BundledCfKey 非明文落地）
- **输入校验**：全套 Validator（HTTP/UNC/文件路径/文件名/正则/长度/非空）
- **路径安全**：SafeId 防目录穿越、VersionInstaller 孤儿清理
- **遥测透明**：TelemetryService 异常/崩溃上报（含 Nat 行为信息，可过滤）
